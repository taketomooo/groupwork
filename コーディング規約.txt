HTML コーディング規約

基本ルール
・HTML5（<!DOCTYPE html>）を使用する
・インデントは 半角スペース2つ
・属性値は必ずダブルクォート " を使用
・構造を明確にするため、適切なタグ（header, main, section 等）の使用を検討する

 ID / class 命名
・id：JavaScript から参照する要素のみ使用
・class：スタイル目的で使用
・命名は kebab-case

 禁止事項
・HTML 内での複雑な JavaScript ロジック記述
・不要な div の多用

JavaScript コーディング規約

 基本ルール
・ES6 構文を使用する
・インデントは 半角スペース2つ
・文末のセミコロンは 省略しない
・ 命名規則
・変数・関数名：camelCase
・定数：UPPER_SNAKE_CASE
・真偽値：is, has, can で始める

 関数設計
・1関数1責務を原則とする
・関数名は「何をするか」が分かる動詞にする

 DOM 操作
・document.getElementById はラッパー関数経由で使用可
・同じ要素を何度も取得しない

 データ管理
・localStorage に保存するデータ構造は統一する
・配列・オブジェクトの構造を変更する場合は影響範囲を確認する

 禁止事項
・グローバルスコープへの不要な変数定義
・マジックナンバー・マジック文字列の直書き

CSS コーディング規約

 基本ルール
・インデントは 半角スペース2つ
・セレクタはシンプルに保つ
・1行1プロパティを原則とする

 クラス命名
・kebab-case を使用
・意味が分かる名前を付ける

 スタイル設計
・色・余白はできるだけ統一する
・ボタンなどの共通要素は再利用可能なクラスにする

 禁止事項
・!important の使用
・タグセレクタへの過度なスタイル指定
